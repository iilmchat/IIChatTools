Безопасность блока
Защита от рекурсии — ParentToolName исключается из tools + явная проверка в цикле.

Лимит шагов — жёсткий (30), пользовательский (по умолчанию 10), конфигурируемый.

Лимит размеров — task ≤ 8000, context ≤ 20000 символов.

Таймаут HTTP — LmStudio:RequestTimeoutSeconds (по умолчанию 300 с).

Все инструменты суб-агента проходят через ToolRegistry с теми же проверками безопасности (PathHelper, ArgumentList, approval whitelist).

Проверка владельца сессии — AgentState привязан к UserId.

Сессии в БД — позволяют диагностировать проблемы и восстанавливать контекст.

Требует подтверждения — по умолчанию инструмент consult_secondary_agent требует подтверждения пользователя (RequiresApprovalByDefault = true).
