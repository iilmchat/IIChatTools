# Известные проблемы IIChatTools

Файл ведётся с версии 1.0 (сентябрь 2026).
Формат записи: `KI-XXX` — краткое название, приоритет, статус.

**Приоритеты:**
- 🔴 Critical — блокирует работу, уязвимость, потеря данных
- 🟠 High — заметная проблема UX или функционала
- 🟡 Medium — косметическая проблема или улучшение
- 🟢 Low — пожелание на будущее

**Статусы:**
- Open — зафиксирована
- In Progress — в работе
- Fixed — исправлена (с указанием версии)
- Won't Fix — не будет исправляться
- Deferred — отложена на более позднюю версию

## Открытые проблемы

### KI-001 — Неинформативное сообщение при отклонении действия
- **Приоритет:** 🟡 Medium
- **Статус:** Open
- **Версия:** v1.0
- **Обнаружено:** 2026-09-15
- **Где:** `/test` → модалка подтверждения → «Отклонить»
- **Описание:** После отклонения действия в поле «Результат» отображается сухое `rejected` и `Действие: rejected`. Причина отклонения, которую пользователь ввёл в prompt, не показывается.
- **Ожидаемое поведение:** Показывать читаемое сообщение: «Действие отклонено пользователем. Причина: <текст>».
- **Файлы:**
  - `wwwroot/js/modules/approvals.js` — вернуть `reason` из промиса
  - `wwwroot/js/modules/test.js` — использовать `reason` при формировании результата
- **План:** Исправить в v1.0.2 (hotfix)
