разработку. Ниже — контекст и правила.

## Контекст проекта

IIChatTools v1.0 — веб-приложение .NET Core 3.1 + EF Core + MSSQL/SQLite,
предоставляющее локальной LLM (LM Studio, OpenAI-совместимый API на :8034)
набор из 40 инструментов: файловая система, выполнение кода, веб-поиск,
браузерная автоматизация (PuppeteerSharp), Git/GitHub, суб-агенты, утилиты.

Ключевые компоненты:
- 4 проекта: IIChatTools.Data, IIChatTools.Services, IIChatTools.API, IIChatTools.Tests
- 6 контроллеров: Home, Auth, Tools, Approvals, Admin, Status
- ToolRegistry + ITool (40 инструментов, auto-discovery через DI)
- Гибридная БД: SqlServer / Sqlite / InMemory
- CompositeAuditService: БД + JSONL-файл (logs/audit/)
- Мультипользовательность: роли Admin/User, первый зарегистрированный = Admin
- Система подтверждений: PendingAction + polling /api/approvals/pending
- Суб-агенты: ISubAgentService с циклом, авто-отладкой через агента-рецензента
- Локализация RU/EN: SharedResources.resx + IStringLocalizer<SharedResources>
- Аутентификация: cookie (Razor) + JWT (API)

## Правила оформления (ОБЯЗАТЕЛЬНЫ)

1. Все комментарии и XML-документация — на русском
2. XML-doc (<summary>, <param>, <returns>, <exception>) обязателен для
   всех public классов, интерфейсов, методов, свойств
3. DI только через конструктор, никогда через ServiceLocator
4. Все I/O-методы — с суффиксом Async
5. Публичные члены — PascalCase, приватные поля — _camelCase
6. Контроллеры: try-catch → возврат { success, data, message }
7. Сервисы: throw с понятным сообщением, не гасить стек
8. ILogger — технические логи; IAuditService — действия пользователей
9. Все файловые пути — через PathHelper.TryGetSafeFullPath
10. CLI — только через ProcessStartInfo.ArgumentList (без конкатенации)
11. Версионирование — обновлять AppVersion.Current
12. Copyright: © 2026 RuChating (iilmchat) · IIChatTools v1.0

## Формат работы

- Давай код полными файлами с XML-документацией
- Указывай путь к файлу в начале каждого блока кода
- При изменении существующего файла — предоставляй полную версию
- Если нужны новые NuGet-пакеты — указывай версию и куда добавить
- В конце каждого блока — краткая сводка (что сделано, что проверить)
- Не забывай про локализацию: новые ключи добавляй в оба .resx (RU и EN)
- При добавлении нового инструмента — 1 файл класса + 1 строка регистрации
  в Startup.cs в соответствующей группе
