# Архитектурные решения (ADR)

**Обновлено:** 2026-10-19

Каталог зарезервирован для отдельных ADR-файлов. Исторически решения
ведутся **внутри** [ARCHITECTURE.md](../ARCHITECTURE.md) — раздел
«ADR-style записи» (ADR-001 … ADR-025). Отдельные файлы здесь не заводились,
чтобы не дублировать источник истины.

## Соглашение

- **Формат имени:** `ADR-NNN-краткое-название.md`.
- **Структура:** Контекст → Проблема → Решение → Последствия → Ссылки.
- **Нумерация:** продолжает нумерацию из `ARCHITECTURE.md`, без переиспользования номеров.
- **Индекс:** при появлении первого отдельного файла — добавить строку в таблицу ниже.
- **Связанные правила:** RULES § 2.5 (дизайн-документы), § 4.51 (ADR-002 — `Func<IToolRegistry>`).
