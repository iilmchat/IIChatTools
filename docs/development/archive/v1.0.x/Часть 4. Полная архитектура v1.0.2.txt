4.2. Ключевые архитектурные решения
#	Решение	Обоснование
1	Слоистость Data → Services → API	Чистое разделение; Services не зависит от API через AppVersionHolder
2	Гибридная БД (SqlServer/Sqlite/InMemory)	Не требует SQL Server от пользователя
3	CompositeAuditService	Аудит в БД и/или файл (JSONL) независимо
4	DI через конструктор везде	Тестируемость, отсутствие ServiceLocator
5	ToolRegistry + ITool	Новый инструмент = 1 класс + 1 строка регистрации
6	Func<ISubAgentService>	Разрыв DI-цикла SubAgent ↔ ToolRegistry
7	path в git/gh инструментах	Работа с несколькими репозиториями в workspace
8	GitContextValidationResult / GhContextValidationResult	Обход запрета out в async-методах
9	HttpClient.DefaultProxy + NO_PROXY	Единственный способ заставить ClientWebSocket использовать прокси с bypass loopback в .NET Core 3.1
10	HttpClientFactoryOptions.HttpMessageHandlerBuilderActions	Единственный способ передать прокси с credentials в IHttpClientFactory на 3.1
11	BrowserLocator	Автоопределение Edge/Chrome — не используем BrowserFetcher
12	--remote-allow-origins=*	Обход блокировки WebSocket в Chromium 111+
13	--proxy-bypass-list=<-loopback>	Обход прокси для WS-соединения с самим Chromium
14	Реалистичный User-Agent	Обход блокировки headless на сайтах
15	PuppeteerSharp 7.1.0	Исправления совместимости с современными Chromium
16	IStringLocalizer<SharedResources>	Единая точка локализации интерфейса
17	PendingAction + polling	Компромисс безопасности и UX без WebSocket
18	KNOWN_ISSUES.md	Реестр проблем и решений
4.3. Поток вызова браузерного инструмента
text
ToolRegistry.ExecuteAsync("browser_open_page")
   ↓
BrowserOpenPageTool
   ├─→ BrowserLocator.Resolve (найти Edge/Chrome)
   ├─→ Puppeteer.LaunchAsync
   │     Args:
   │       --no-sandbox
   │       --remote-allow-origins=*
   │       --proxy-server=http://proxy.example.local:8080
   │       --proxy-bypass-list=<-loopback>
   │       --ignore-certificate-errors
   │
   ├─→ page.SetUserAgentAsync (реалистичный Chrome UA)
   ├─→ page.AuthenticateAsync (Basic Auth для прокси)
   ├─→ page.GoToAsync (через прокси → сайт)
   ├─→ page.GetContentAsync + EvaluateExpressionAsync
   └─→ ToolResult.Ok({ url, title, text, htmlLength })
