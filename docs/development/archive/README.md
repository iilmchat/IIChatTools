## Почему не удалили

- **История.** В `git log --all` файлы всё равно остаются, но держать их в рабочей папке — глаза мозолят.
- **Контекст.** При чтении старых коммитов можно быстро глянуть, «как было в v1.0».
- **Правило RULES § 3.13** — «удалять временные скрипты после задач». Архив — исключение: это не скрипты, а исторические документы.

## Что можно удалить совсем (по желанию)

Если архив надоест — `git rm -r docs/development/archive/v1.0.x` — файлы останутся в истории git, но исчезнут из working tree.
