5.3. План v1.1 — рекомендуемый порядок
Обязательно (must-have, 7–9 недель):

.NET 8 LTS — критично, поскольку 3.1 EOL (3–5 дней)

Rate limiting — AddRateLimiter, per-user (2 дня)

Health checks + метрики Prometheus (3 дня)

SignalR вместо polling (5–7 дней)

Retention-политика аудита — BackgroundService (2 дня)

Hot-reload настроек через IOptionsMonitor (3 дня)

Расширение тестов (unit + integration, ≥70% coverage) (10 дней)

Docker + docker-compose + GitHub Actions (4 дня)

Документация (Developer Guide, API Reference, Security Guide) (3 дня)

Желательно (should-have, 4–5 недель):

Стриминг ответов LM Studio (SSE) — 5 дней

Chat UI с историей — 10–15 дней

RAG (Qdrant + эмбеддинги) — 10–15 дней

2FA для Admin — 3 дня

Отложить до v1.2:

MCP-совместимость (stdio + SSE)

Матрица tool-policy per-role

HMAC-подпись AuditLog

Helm chart для K8s

Шифрование секретных AppSetting
