Как использовать в коде
1. В Razor-представлениях
cshtml
@using Microsoft.AspNetCore.Mvc.Localization
@inject IViewLocalizer Localizer

<h1>@Localizer["Добро пожаловать в IIChatTools v1.0"]</h1>
<a class="btn btn-primary" asp-action="Status">@Localizer["Перейти"]</a>
2. В контроллерах и сервисах (через IStringLocalizer<T>)
csharp
using Microsoft.Extensions.Localization;

public class AuthController : Controller
{
    private readonly IStringLocalizer<SharedResources> _localizer;

    public AuthController(IStringLocalizer<SharedResources> localizer)
    {
        _localizer = localizer;
    }

    [HttpGet]
    public IActionResult Login()
    {
        ViewData["Title"] = _localizer["Вход"];
        return View();
    }
}
3. Обязательно создать маркерный класс SharedResources
Путь: IIChatTools.API/Resources/SharedResources.cs

csharp
namespace IIChatTools.API.Resources
{
    /// <summary>
    /// Маркерный класс для ресурсов локализации интерфейса.
    /// Используется совместно с файлами SharedResources.resx и SharedResources.ru.resx.
    /// </summary>
    public class SharedResources
    {
    }
}
4. В Startup.cs уже настроено:
csharp
services.AddLocalization(options => options.ResourcesPath = "Resources");
services.AddControllersWithViews()
        .AddViewLocalization()
        .AddDataAnnotationsLocalization();
5. Переключение языка в UI
Добавьте в _Layout.cshtml небольшой переключатель:

cshtml
<div class="language-switcher">
    <a href="?culture=ru&ui-culture=ru">RU</a> |
    <a href="?culture=en&ui-culture=en">EN</a>
</div>
Или через cookie/cookie-based провайдер (рекомендуется для сохранения выбора пользователя).
